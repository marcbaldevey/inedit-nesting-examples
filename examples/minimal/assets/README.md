# Assets

Put the images of the example here, with the file names listed in `../config.js` (`images[].file`).

- Formats the browser shows: PNG, JPEG, WebP, GIF, AVIF, SVG.
- For true-shape nesting use images with a transparent background (or a uniform background colour with a margin).
- The size printed is the one in `config.js`, not the image's own size.

A missing file is drawn as a grey box with the size from `config.js`; the PDF cannot be generated until it exists.
